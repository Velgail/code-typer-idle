# Code Typer Idle

日銭を稼ぎ、コードを学び、ゲームを作る。理解度と制作資金をやりくりする、日本語の無料インクリメンタルゲームです。

クリック、または出題されたコードを正確にタイプして入力します。日銭ワークは資金に、写経は分野別の理解度に、開発は有効コードに変わります。理解不足の開発には不具合が混入します。技術的負債は、それとは別の仮実装や継ぎ足しによる未整理部分。理解して書いても発生し、今後の追加・変更に手間がかかり、不具合も混ざりやすくなります。開発・設計の経験が浅いほど無意識に積み上がり、経験を積むと発生を抑えられます。開発方針で速さと後の整理作業を選びます。

最初の数当てゲームから、インディー作品、AAA、永続オンライン宇宙へ。AAAの先には世代ごとに要求規模が増す多元宇宙エンジンと、コード資産を引き継ぐ再出発があります。100万行で終了するゲームではありません。

## 起動

公開用ファイルを同梱しているため、遊ぶだけならビルドは不要です。Python 3がある環境なら、リポジトリのルートで実行します。

```sh
python3 -m http.server 4173 --directory docs
```

ブラウザで `http://localhost:4173/` を開きます。`npm run dev` はソースの変更をビルドしてから同じサーバーを起動します。ES Modulesを使うため、HTMLをファイルとして直接開く方法には対応していません。

## GitHub Pages

公開する静的ファイルはすべて `docs/` にあります。リポジトリ名を含むサブパスでも動く相対URLを使っています。

1. この変更を公開対象ブランチ（通常は `main`）にコミットしてpushします。
2. GitHubの **Settings → Pages → Build and deployment** を開きます。
3. **Source: Deploy from a branch** を選びます。
4. 公開するブランチと **`/docs`** を選んで保存します。

このリポジトリの公開先は、設定後に `https://velgail.github.io/code-typer-idle/` となる想定です。実際の公開状態とURLはGitHubのPages画面で確認してください。

`docs/.nojekyll` を同梱しています。外部CDN、広告、課金、API、バックエンド、アクセス解析は使いません。プレイデータはブラウザ内に保存します。

## 操作と進行

画面上部の目標から教材を購入し、学習・開発へ進めます。最初の¥1,500を教材に使うか、事務を自動化するOCRへ先に投資するかを選べます。支払いや売上などの集計は、必要になった段階で表示します。

開発中は制作量とビルド結果を確認します。開発方針や負債の内訳、変更効率、検証履歴は必要なときに開けます。「作品を公開」は進捗と不具合の条件を満たすと押せるようになり、負債が残っているだけで公開を妨げません。公開までの不足文字数や、修正が必要な状態はボタンの近くに表示します。公開結果の「次の企画へ」から、次の目標と操作へ戻れます。

| 操作 | 内容 |
| --- | --- |
| クリック | 現在の作業に1入力 |
| コードタイピング | 事務は原票からCSV化、学習・開発は出題コードを入力。完入力で追加報酬 |
| 言語選択 | C++ / C# / Rust / Go / Python / Java / SQL / Lua |
| 作業タブ | 日銭 / 学習 / 開発の切替。数字キーでタブは切り替わりません |
| Esc | コード入力欄からフォーカスを外す |
| 学習分野ボタン | 文法、設計、描画、基盤から選択。分野ごとの教材が必要 |
| レビュー・整理 | 必要理解度100%で、まず不具合を修正し、残りの作業で構造を整理 |
| 途中ビルド・テスト | 小さな変更ごとに自動検証。修正や整理の後も最新版を再検証 |
| 素材制作の外注 | グラフィック・音響の制作費を作品ごとに支払い、品質を高める。自作も可能 |
| 作品を公開 | 進捗100%、ビルド正常、不具合が表示の基準以下で公開。技術的負債は残せる |
| 自動開発スイッチ | 開発ユニットだけを停止・再開。マクロは稼働を継続。研究は教材が必要 |
| ロードマップ | 今後の企画と、資産を引き継ぐ再出発 |
| 設定 | 打鍵音、演出削減、一時停止、セーブの書き出し・読み込み |

コード表示をクリックすると、カーソル位置で直接タイプできます。正解はすぐコード側へ確定し、入力の控えは残しません。誤入力だけをカーソルのそばに表示し、Backspaceや選択編集で直せます。確定済みの文字は削除・再入力しても重複計上しません。保存復帰ではコード側の進捗から再開します。伝票は確定済みCSVだけを表示し、未入力の正解は表示しません。

半角で入力します。全角補正や専用のIME変換処理は持たせず、通常の文字入力を判定します。貼り付け、ドロップ、キー長押しは数えません。コード入力中のTabは正解に合わせてタブ文字または最大4空白を入力し、報酬と入力回数は1打鍵分。Shift+TabまたはEscでコードからフォーカスを外せます。モバイルではコード位置をタップして画面キーボードを開きます。数字キー単独で作業タブを切り替える操作はありません。

学習には「コードを写す」「言語別の講座」「参考コードを読む」があります。すべて分野ごとの教材が必要です。

- 通常出題は8言語×4分野×16本＝512本。16データずつ、8,192問を収録しています。英語コメントを1つ打ち終えるたびに、出題コード内のそのコメントを日本語に置き換えます。設定で英語表示にも切り替えられます。共通アルゴリズムに加え、各言語のコンテナ・所有権・コールバック・非同期処理などを扱います。
- 言語別講座はExercismのMIT教材1,062演習。名前空間・クラス・クロージャのまとまりを保った3,562入力区間に分けています。変更のない支給関数は参照欄に残し、独立した問題にはしません。importや属性は対象の宣言と一緒に入力します。入力前に日本語で処理の目的・引数や変数の用途・所属を確認できます。概念の前提を考慮した順序と応用の難度を保持し、課題・周辺ファイル・作者・出典を参照できます。入力する英語コメントとPythonのdocstringに日本語対訳を同梱し、元コードの開始・終了位置で表示を判定します。誤った文字では表示せず、置換した表示は保存復帰でも再現し、別の問題へは持ち越しません。入力の正誤判定と保存位置には元の英語を使います。講座は開いたときに読み込むため、通常プレイの初回読込を重くしません。
- 参考コードの読解は4択で処理結果を答えます。初回正解で120学習作業量。不正解は加算なしで解説を表示し、同じ題材の再読込・再回答では重複加算しません。一言語・一分野16本を一巡したら写経へ続けられます。回答と講座の完了記録は保存し、再出発ではリセットします。

| 言語 | 講座の演習 | 入力区間 |
| --- | ---: | ---: |
| C++ | 100 | 318 |
| C# | 178 | 485 |
| Rust | 110 | 405 |
| Go | 166 | 656 |
| Python | 149 | 442 |
| Java | 158 | 546 |
| SQL（SQLite） | 81 | 417 |
| Lua | 120 | 293 |

通常出題は、開発用テスト環境で実際にコンパイル・実行して解答を照合します。完入力後は呼び出しに対する戻り値、SQLなら問い合わせ結果を表示。関数の定義だけで標準出力が発生したようには表示しません。講座の参考実装は同じ実行検証をしていないため、実行成功とは表示しません。ブラウザ上で任意の入力をコンパイルする機能はありません。

正解文字はクリックの1.5倍、誤入力なしの完入力でコードは合計2倍、原票入力は合計2.25倍の作業量を得ます。原票は読み取りと整形の時間を見込み、完入力ボーナスを厚くしています。誤入力は完入力ボーナスを減らします。

現在企画の制作文字数・必要理解度・不足分野を作業パネル上部に表示します。要求の半分以下では制作進捗が出ず、半分超から試作、100%で通常制作へ。不足分野の学習ボタンで直接移動できます。不具合が公開条件を超えると、学習と修正を先に案内します。技術的負債は内訳・変更効率を表示し、自作ライブラリの流用では未整理部分の25%を次作へ引き継ぎます。

日銭ワークは伝票画像のデータ化という事務作業です。原票の画像を読み、伝票番号・日付・品名・数量・単価をCSVへ整えます。日付はYYYY-MM-DD、金額は記号や桁区切りを除きます。完成済みの入力文字列は画面に出さず、原票と入力仕様を示します。プログラミング知識は増えません。画像原票256種類を同梱。日付は同日に複数件発行される営業日の並び、品目と数量は別々の固定乱数で選び、品目ごとの価格と少量の数量値引きを使います。数量の単位も本・冊・台・箱など品物に合わせます。再読込や端末間のセーブ移動でも原票は同じです。更新前の入力途中の原票は、その1問を終えてから新版に切り替えます。タイピング中は原票をコンパクトに表示して入力位置と同時に確認でき、CSVの整形規則は必要なときだけ開けます。OCR・入力マクロで読み取りと入力を自動化できます。学習とゲーム開発では、引き続き8言語のコードを出題します。

AAAは4億文字・約1,000万行相当を制作します。開発中に小さな変更ごとのビルド・テストを繰り返し、完成後の公開前にも最新変更を確認します。

初期資金は¥100。日銭ワークは100作業量ごとに1件を納品し、初期報酬は1件¥100です。1クリック＝1作業量で、未完成の仕事は現金になりません。作業を切り替えても途中進捗は保存され、着手時の単価で精算します。¥1,500のOCR・入力マクロを導入すると、毎秒10作業量を自動で処理し、学習や制作をしている間も納品を続けます。増設は追加の処理量を増やします。マクロと同額の基礎教本も、受託の収益で購入します。初作に必要な基礎文法12までは、学ぶ量に応じて一定のペースで理解度が伸びます。その先は、理解度が高くなるほど次の1ポイントに多くの学習量が必要です。

## 売上と支払い

未公開の個人制作と、無料のオフライン作品には固定費がありません。教本・道具・自動化設備は表示価格で購入する買い切りです。2作目からは素材制作を外注でき、支払先・一度の制作費・納品後の品質を注文前に示します。グラフィックと音響の支払額を作品別に保存し、次作へ自動発注しません。最初の基礎教本は¥1,500で、学習には分野ごとの教材が必要です。

| 支払う費用 | 支払先 | 発生条件・精算 |
| --- | --- | --- |
| 販売・決済手数料 | ゲーム配信ストア | 商用作品の初回・継続売上の25%。売上が入るときに控除 |
| オンライン作品のサーバー稼働料 | ホスティング会社 | 公開中の時間分。日の終わりに精算 |

オンライン作品のサーバー代は、開発画面の公開ボタン付近とロードマップに表示します。公開したゲームの一覧から「公開停止」を選ぶと、その後のサーバー代と継続売上が止まります。停止までに発生した料金は残り、再開すると料金と売上が再開します。無料公開でも、サーバーを動かすオンライン作品の稼働料は発生します。

上部の「支払い内訳」で、現在の用途・支払先・金額を確認できます。「サーバー運用の最適化」はサーバー代を25%削減し、オンライン作品の開発段階で解禁します。販売手数料は変わりません。自動的に事務所を借りたり、公開本数で維持費を増やしたりする仕組みはありません。

必要理解度を満たして品質60以上で公開すると、2本目以降の作品が有料発売になります。最初の作品は無料で、公開により次の案件・設備が解禁されます。新作公開後は自動開発を停止するので、次の要求理解度を確認してから再開してください。

## セーブ

- 5秒ごと、タブを隠したとき、ページを離れたときに `localStorage` へ保存。
- 直前の保存内容をバックアップ。メインデータの破損時は復旧を試みます。
- 設定からJSON形式で書き出し・読み込み。読み込みは現在の進行を置き換えます。
- 離席中は最大8時間分の自動処理・売上・サーバー代を計算。購入や公開は手動です。
- Web Locks対応ブラウザでは、同じオリジンの別タブからの上書きを防止します。
- プライベートブラウズ、容量制限、ブラウザデータの削除に備えて、定期的な書き出しをおすすめします。

保存先のキーは `code-typer-idle:save:v1`。複数のGitHub Pagesプロジェクトは同じドメインを共有するため、他作品と衝突しない名前にしています。サーバーへのデータ送信はありません。

旧セーブの現金・理解度・設備・作品・資産を引き継ぎます。旧版の「負債」は意味が異なるため、不具合の修正作業へ移します。旧事務所の未使用積立は現金に戻し、未精算の旧費用は取り消します。新しい契約を更新前の離席へさかのぼって適用しません。

## バージョン更新とキャッシュ

公開用JavaScriptとCSSは内容に応じたファイル名で生成し、実行モジュールの参照を同じビルドへ揃えます。講座の資料データは個別の内容ハッシュで共有し、画面だけの修正で再配信・再読込しないようにします。新旧ファイルが混在する更新を防ぎ、以前の配信ファイルも残します。

起動時・タブへ戻ったとき・60秒ごとに `version.json` をキャッシュなしで確認します。更新があれば「保存して更新」を表示し、保存成功後に新しいURLで再読み込みします。保存失敗や別タブ起動時は更新を止め、セーブを保護します。通信できないときはプレイを継続します。更新のためにlocalStorageやブラウザデータを削除する必要はありません。

指紋付き配信より前のHTMLには、旧URL `js/app.js` から最新版へ移る入口を残しています。すでに開いている旧版には更新検知処理がないため、初回はページを開き直します。旧版の全ファイルが強くキャッシュされて開き続ける場合は、[更新用URL](https://velgail.github.io/code-typer-idle/?v=1.2.0)を一度開いてください。以降はゲーム内で更新を検知します。

```text
src/
  core.js           DOMに依存しないゲームルールと保存形式
  app.js            入力、画面更新、音、保存、ブラウザ連携
  typing.js         多言語の出題、途中問題の版管理、正誤判定
  curriculum.js     通常教材・コメント・読解問題と計算過程
  idioms.js         言語固有の構文・標準機能の教材
  courses.js        言語別講座の参照と進行
  course.js         SHA固定のExercism教材（遅延読込）
  learningguide.js   入力前の目的・変数の日本語説明
  office.js         伝票画像・入力仕様・事務用の256問
  pacing.js         開発検証用の到達時間（画面へは配信しない）
  updates.js        更新検知と保存後の再読み込み
docs/
  index.html        画面とダイアログ
  style.css         UIのスタイル元
  build/            指紋付きの公開用JavaScript・CSS
  version.json      配信中のバージョン情報
  assets/           同梱アイコン
  js/               旧キャッシュからの移行入口・旧版の依存ファイル
scripts/
  build.mjs         依存なしで配信用ファイルを生成
  simulate-balance.mjs  入力速度と離席条件別の進行計測
tests/
  core.test.js      ゲームルール・会計・旧セーブ移行
  curriculum.test.js  コメント対訳・読解・制作案内
  course.test.js    講座の文脈・進行・保存サイズ
  typing.test.js    出題8,192問、正誤、報酬、保存
  balance.test.js   3〜7日の進行と高速入力条件の回帰検証
  browser.mjs       Chromiumの操作・表示・キャッシュ更新検証
DESIGN.md           数式と企画からの具体化
```

Node.js 22以降でルールのテストを実行できます。外部パッケージは不要です。

```sh
npm run build
npm test
```

ソースを変更したら `npm run build` を実行し、`docs/` の生成物もコミットしてください。CIは再ビルドとの差分がないことを確認し、ルールとChromiumのブラウザ検証を実行します。バランス変更時は先に `npm run balance -- --write` を実行します。

ブラウザテストだけはPlaywrightが必要です。

```sh
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

ブラウザテストは自身でローカルサーバーを起動し、終了時に停止します。既存サーバーを使う場合は `CTI_TEST_URL`、Chromiumの実行パスを指定する場合は `CHROMIUM_PATH` を設定できます。スクリーンショットはGit管理外の `work/` に出力します。

ルール・会計・出題・進行をテストします。ブラウザテストではコードへの直接入力、正解の即確定と空buffer、誤入力の表示と編集、重複報酬防止、貼り付けとキー長押しの拒否、8言語、セーブ復帰、公開、作品一覧、開発用表示の撤去、支払先と公開停止、設定、書き出し・読み込み、別タブ制御を検証。キャッシュ更新は長期キャッシュした旧HTML・モジュール・バージョン情報を残し、別バージョンへの配信切替、保存失敗時の停止、セーブ維持、オフライン継続を実ブラウザで確認します。数字入力がタブを変えないこと、入力フォーカスの復帰、教材の未購入・購入直後・分野切替・再読み込みも確認します。画面幅1440 / 1024 / 768 / 390 / 360pxでも表示を確認します。シミュレーションは購入方針を固定した比較で、実プレイ全体の保証ではありません。

教材そのものを検証する場合は `npm run test:curriculum -- --all` を実行します。C++、C#（Mono）、Rust、Go、Python、Java、SQLite、Luaの実行環境が必要です。`--all` を省略すると、利用できるコンパイラだけを実行して対象を報告します。CIは8言語すべての8,192問を実行します。

講座データの再生成にはPythonと`tree-sitter-language-pack==1.22.1`を使います。`python scripts/import-course.py --download`で固定した取得元を`work/tracks/`へ展開し、生成します。生成時に上流コードやスクリプトを実行しません。概念・前提・難度・作者・ライセンスとコメントの対訳を維持し、同じコード区間のIDは安定させます。出題単位を変更した場合も、公開済みの旧教材を必要時だけ読み込み、入力途中の文字列・カーソル・未確定報酬を保持します。完入力後に新しい区間へ進みます。
