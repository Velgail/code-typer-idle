# Code Typer Idle

日銭を稼ぎ、コードを学び、ゲームを作る。理解度と生活費をやりくりする、日本語の無料インクリメンタルゲームです。

クリック、または出題されたコードを正確にタイプして入力します。日銭ワークは資金に、写経は分野別の理解度に、開発は有効コードに変わります。理解不足の開発はエラーや技術的負債になります。自動化も、コードをレビューできなければビルドを壊します。

最初の数当てゲームから、インディー作品、AAA、永続オンライン宇宙へ。AAAの先には世代ごとに要求規模が増す多元宇宙エンジンと、コード資産を引き継ぐ再出発があります。100万行で終了するゲームではありません。

## 起動

Node.jsの依存パッケージやビルドは不要です。Python 3がある環境なら、リポジトリのルートで実行します。

```sh
python3 -m http.server 4173 --directory docs
```

ブラウザで `http://localhost:4173/` を開きます。`npm run dev` でも同じサーバーを起動できます。ES Modulesを使うため、HTMLをファイルとして直接開く方法には対応していません。

## GitHub Pages

公開する静的ファイルはすべて `docs/` にあります。リポジトリ名を含むサブパスでも動く相対URLを使っています。

1. この変更を公開対象ブランチ（通常は `main`）にコミットしてpushします。
2. GitHubの **Settings → Pages → Build and deployment** を開きます。
3. **Source: Deploy from a branch** を選びます。
4. 公開するブランチと **`/docs`** を選んで保存します。

このリポジトリの公開先は、設定後に `https://velgail.github.io/code-typer-idle/` となる想定です。実際の公開状態とURLはGitHubのPages画面で確認してください。

`docs/.nojekyll` を同梱しています。外部CDN、広告、課金、API、バックエンド、アクセス解析は使いません。プレイデータはブラウザ内に保存します。

## 操作と進行

| 操作 | 内容 |
| --- | --- |
| クリック | 現在の作業に1入力 |
| コードタイピング | 出題どおりの正解文字で報酬、完入力で追加ボーナス |
| 言語選択 | C++ / C# / Rust / Go / Python / Java / SQL / Lua |
| `1` / `2` / `3` | 入力欄の外で、日銭 / 学習 / 開発の切替 |
| Esc | コード入力欄からフォーカスを外す |
| 学習分野ボタン | 文法、設計、描画、基盤から選択 |
| リファクタリング | 必要理解度100%で技術的負債を修復 |
| ビルドして公開 | 進捗100%、ビルド正常、負債10%以下で公開 |
| 自動開発スイッチ | 開発ユニットだけを停止・再開。マクロと研究は常時稼働 |
| ロードマップ | 今後の企画と、資産を引き継ぐ再出発 |
| 設定 | 打鍵音、演出削減、一時停止、セーブの書き出し・読み込み |

任意キーの連打では報酬を得られません。コードタイピングでは空白と改行を含めて一致を確認し、誤入力は進めず、正しい文字を打ち直せます。貼り付け、ドロップ、キー長押しは数えません。Tabはフォーカス移動のままで、インデントは空白を入力します。モバイルでもクリックと画面キーボードを使えます。

出題は8言語×4分野×4種類のコード例×16通りのデータ差分で、計2,048問を同梱。コードの断片を使うため、周辺の宣言やライブラリの読み込みを省略した例もあります。出題コードを実行することはありません。正解文字でクリックの1.25倍、誤入力なしの完入力で合計1.5倍の作業量を得ます。誤入力は完入力ボーナスを減らします。

初期資金は¥100、初期クリック報酬は¥1です。¥1,500のデータ入力マクロと同額の基礎教本を、日銭を稼いで購入します。食費と家賃の平均は¥0.2/秒、最初のマクロは¥0.25/秒。マクロ1台で生活は維持できますが、それだけでは設備を次々に買えません。

学習量は教材1レベルごとに+100%、モニターは+25%。キーボードの手動入力は+25%、IDEの完全理解時の手動開発は+35%ずつ増えます。各設備内では加算です。理解度が高くなるほど、次の1ポイントに必要な学習量も増えます。

数当てゲームの売上はゼロです。完成すると理解度が増え、高単価ワークと開発設備を解禁できます。有料作品は品質60以上かつ必要理解度100%以上で販売され、初回売上と継続売上が入ります。新作公開後は自動開発を停止するので、次の要求理解度を確認してから再開してください。

## 到達時間の目安

新規セーブ・周回なしで、初回AAAまで放置込み3〜7日を基準に調整しています。ゲーム内の開発ロードマップにも同じ表を表示します。

| 到達点 | クリック8回/秒・連続 | 正確な入力30文字/秒・連続 | クリック8回/秒・離席あり |
| --- | ---: | ---: | ---: |
| 基礎教本 | 約6分 | 約1分 | 約6分 |
| 最初の無料作品 | 約27分 | 約5分 | 約27分 |
| 最初の有料作品 | 約2.1時間 | 約27分 | 約10時間 |
| インディー作品 | 約8.6時間 | 約2時間 | 約34時間 |
| スタジオ規模の3D作品 | 約32時間 | 約12時間 | 約72時間 |
| AAA | 約113.5時間 | 約74.1時間 | 約168時間 |

タイピング列は30文字/秒を全問正解し、完入力ボーナスも得る上限性能です。通常の正確なコード入力はこれより遅くなります。「離席あり」は最初に1時間、その後は日中16時間の活動帯に2時間ごと5分操作し、夜は8時間離席。AAAまでの実操作時間は約5.6時間です。購入順や周回によっても変わり、最速手順を保証する数字ではありません。

計測では資源を注入せず、実際の報酬で購入します。手順は `scripts/simulate-balance.mjs` に記載。`npm run balance` で再計測でき、`npm run balance -- --write` でゲーム内の表を更新します。

## セーブ

- 5秒ごと、タブを隠したとき、ページを離れたときに `localStorage` へ保存。
- 直前の保存内容をバックアップ。メインデータの破損時は復旧を試みます。
- 設定からJSON形式で書き出し・読み込み。読み込みは現在の進行を置き換えます。
- 離席中は最大8時間分の自動処理と生活費を計算。購入や公開は手動です。
- Web Locks対応ブラウザでは、同じオリジンの別タブからの上書きを防止します。
- プライベートブラウズ、容量制限、ブラウザデータの削除に備えて、定期的な書き出しをおすすめします。

保存先のキーは `code-typer-idle:save:v1`。複数のGitHub Pagesプロジェクトは同じドメインを共有するため、他作品と衝突しない名前にしています。サーバーへのデータ送信はありません。

バランスv2でも旧セーブの資金、理解度、設備、公開作品、資産を引き継ぎます。新しい報酬・学習式だけが適用され、タイピング設定は安全な初期値で追加されます。旧セーブは上の到達時間の目安には含みません。

## 開発と検証

```text
docs/
  index.html        画面とダイアログ
  style.css         レスポンシブな3カラムUI
  assets/           同梱アイコン
  js/core.js        DOMに依存しないゲームルールと保存形式
  js/app.js         入力、画面更新、音、保存、ブラウザ連携
  js/typing.js      多言語の出題と正誤判定
  js/pacing.js      シミュレーションから生成する到達時間
scripts/
  simulate-balance.mjs  入力速度と離席条件別の進行計測
tests/
  core.test.js      ゲームルールの検証
  typing.test.js    出題2,048問、正誤、報酬、保存の検証
  balance.test.js   3〜7日の進行と高速入力条件の回帰検証
  browser.mjs       Chromiumによる操作・表示検証
DESIGN.md           数式と企画からの具体化
```

Node.js 22以降でルールのテストを実行できます。外部パッケージは不要です。

```sh
npm test
```

ブラウザテストだけはPlaywrightが必要です。

```sh
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

ブラウザテストは自身でローカルサーバーを起動し、終了時に停止します。既存サーバーを使う場合は `CTI_TEST_URL`、Chromiumの実行パスを指定する場合は `CHROMIUM_PATH` を設定できます。スクリーンショットはGit管理外の `work/` に出力します。

ルール・出題・進行の30件をテストします。ブラウザテストでは正しいコード入力、誤入力、貼り付けとキー長押しの拒否、8言語、セーブ復帰、公開、作品一覧、到達時間表、設定、書き出し・読み込み、別タブ制御を検証。画面幅1440 / 1024 / 768 / 390 / 360pxでも表示を確認します。シミュレーションは購入方針を固定した比較で、実プレイ全体の保証ではありません。
