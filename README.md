# Code Typer Idle

コードを学び、自分で企画したゲームを完成させ、その経験で次の制作に挑む日本語の無料インクリメンタルゲームです。クリックと正確なタイピングで学習・開発・素材制作・修正を進め、教本や制作設備へ投資します。

開発ロードマップでは、最初に数当てゲームとブロック崩しを無料公開します。そこで覚えた制作の手順や遊びの工夫を持って再出発し、小さな有料作品へ。いくつもの開発人生を経て、設計の経験、チーム、制作基盤を揃え、AAA以上の規模に挑みます。100万行で終了するゲームではありません。

## 起動

公開用ファイルを同梱しているため、遊ぶだけならビルドは不要です。Python 3がある環境なら、リポジトリのルートで実行します。

```sh
python3 -m http.server 4173 --directory docs
```

ブラウザで `http://localhost:4173/` を開きます。`npm run dev` はソースの変更をビルドしてから同じサーバーを起動します。ES Modulesを使うため、HTMLをファイルとして直接開く方法には対応していません。

## GitHub Pages

公開する静的ファイルはすべて `docs/` にあります。リポジトリ名を含むサブパスでも動く相対URLを使っています。

1. この変更を公開対象ブランチ（通常は `main`）にコミットしてpushします。
2. GitHubの **Settings → Pages → Build and deployment** を開きます。
3. **Source: Deploy from a branch** を選びます。
4. 公開するブランチと **`/docs`** を選んで保存します。

このリポジトリの公開先は、設定後に `https://velgail.github.io/code-typer-idle/` となる想定です。実際の公開状態とURLはGitHubのPages画面で確認してください。

`docs/.nojekyll` を同梱しています。外部CDN、広告、課金、API、バックエンド、アクセス解析は使いません。プレイデータはブラウザ内に保存します。

## Quizで実装する

開発タブの「Quizで実装」、または学習タブの「Quiz」から、コードを自分で書いて試せます。選んだ分野の無料教材を開くと利用できます。C++・C#・Rust・Go・Python・Java・SQL・Luaそれぞれに、文法・設計・描画・基盤の実装課題を用意しています。写経教材の処理を引数で呼び出す課題へ作り直し、SQLは入力テーブルを入れ替えて同じ問い合わせを試します。

仕様とテストケースを読み、エディターの関数を編集して「テストを実行」を押します。全ケースに成功するとクリアです。失敗時は入力・期待値・実際の結果を比較でき、コンパイルエラーと実行時エラーも表示します。解答例は合格後に開けます。Tabで字下げ、Ctrl / ⌘ + Enterで実行、実行中は取り消せます。課題は選択欄から自由に切り替えられます。

最初の数当てゲームでは、入力範囲の確認、正解との比較、勝敗と残り回数の判定を順に作ります。一つの部品をテストすると、その部品の範囲まで制作が進み、次の部品へ移ります。部品ごとに必要な文法理解度は4→8→12。3部品を組み込むと、作品の公開へ進めます。既に進めた制作量は引き継ぎます。

初回成功の学習報酬は、同じ教材を完全に写経した作業量の4回分。教本・設備の効果が乗り、自動学習の未確認分も新しく学ぶ理解の最大3倍まで確かめます。開発では、企画に必要な理解度が揃えば、さらに写経2回分の作業量を実装へ適用します。実際の進捗は残りの制作量や開発方針・変更効率に従い、レビュー・整理中は修復へ使います。素材制作や未払い費用の代わりにはなりません。

実装の効果は設備と経験でも伸びます。Quizを使い切った後も、コードタイピング・クリック・自動開発で制作を続けられます。

学習報酬は課題ごとに初回のみ、実装報酬は作品ごとに1回です。学習で先に解いた課題も、新しい作品へ実装できます。企画の保留・再開や機能追加では同じ作品の実装回数は戻りません。不合格や再提出だけでは報酬は増えません。達成記録と直近12題の入力コードをセーブに保存し、写経・講座・参考コード読解も引き続き利用できます。旧版で解いた課題は、もう一度合格すると新しい学習報酬を一度だけ受け取れます。

Quizで失敗した題材を以前に写経していれば、「写経した教材を見直す」からそのコードと解説を開けます。入力途中の解答と失敗ケースを残して比較できます。教材の閲覧による報酬はありません。写経履歴は再出発でも持ち越します。古いセーブでは、記録から確認できる直前の1題だけを補完します。

実行を押した言語の処理系だけを読み込み、ブラウザのWorker内でコンパイル・評価します。ソースを採点サーバーへ送信しません。初回の読み込み量は言語によって異なり、Rustは約54MB、C++は約30MBあります。JavaはWasm GC対応ブラウザが必要です。教材用の実行環境なので、各言語の全ライブラリ・OS機能を提供するものではありません。対応ソース・ライセンスは[同梱処理系の案内](QUIZ_RUNTIMES.md)にまとめています。

## 最初の2本と再出発

1. 画面上部の「無料教材を開く」から基礎文法のオンライン教材を開きます。
2. 「写経・学習」で文法の理解度を12まで上げ、「ゲーム開発」へ進みます。
3. 数当てゲームを3,000文字まで制作します。ビルド失敗や要修正の案内があれば学習・修正し、「作品を公開」を押します。
4. 次のブロック崩しでは、文法24・設計8・描画8を目指します。設計と描画も無料教材を開いて学べます。目標と分野ボタンに必要量と達成状況が表示されます。
5. 9,000文字のブロック崩しを完成・無料公開したら、「経験を引き継いで再出発」で持越し内容を確認します。確定すると、覚えた知識と経験を使う次の人生が始まります。
6. 次の人生では小さな有料作品の学習目標へ進みます。必要な理解度を学び、完成・発売して、その売上を教本や設備へ投資します。別の規模の新作を選ぶときはロードマップを開きます。

最初の2本に現金の完成報酬はありません。無料教材で学べるため、教本・OCRの購入や事務作業は必須ではありません。有料教本は学習効率への任意の投資で、最初の1冊ならその分野の学習量が2倍になります。

再出発で持ち越すのは「制作経験」「設計の勘」「遊びの発見」、確認済みの技術理解度、開いた無料教材、講座の履修記録・読解の回答・Quizの達成と未完コード、実績と累計記録です。所持金、購入した教本・設備、公開作品とその売上、制作途中のコード、制作済みの自作基盤や事務案件は手放します。自由企画で公開して確かめた知見も持ち越します。自動学習の未確認分は持ち越しません。

経験は完成時に記録され、再出発すると次の人生で効果を発揮します。無料習作の経験は生涯に一度、有料の規模では各人生の最初の完成で獲得します。同じ人生に同規模の別作品を作って販売できますが、完成経験は重複しません。各規模で覚えられる経験には上限があり、より大きな企画へ進む必要があります。ロードマップで不足している経験・設備を確認できます。ロードマップの未着手企画は切替可能で、制作を進めた作品は公開してから次を選びます。自由企画は途中でも保留できます。

## 自由に企画して作る

「自由企画」は、ロードマップの固定作品と別に、自分で遊びと規模を決める入口です。最初から使えます。

1. 「自由企画」を開き、作品名と主ジャンルを選びます。テーマは任意で3つまで選べます。
2. 見た目・音・操作、ひとり用／協力／対戦、通信方式と同期、画面分割、エンジン、対応環境、販売方式と配信先を選びます。
3. 「仕組みと内容を足す」で必要な機能を探し、ステージ・敵種類・章・曲などの数量を決めます。成立に必要な依存機能は自動で含まれます。
4. 素材ごとに自作・既製素材の購入・制作委託を選び、見積もりでコード、素材作業、支払先と費用、必要知識を確認します。矛盾する構成は、表示された案内に従って修正します。
5. 「この企画を始める」で制作へ進みます。知識や資金が足りなくても着手でき、学習と資金集めは途中で行えます。制作費を払える場合は着手時に精算し、足りなければ未払いとして残ります。
6. 「ゲーム開発」で「コードを書く」「素材を作る」を切り替えます。素材は「素材の制作を進める」をクリック／タップして描画・録音・執筆を進めます。この間はコード入力欄が隠れ、タイピング報酬は発生しません。コードと自作素材を完成させ、未払いを精算し、ビルドと不具合を確認して公開します。

「保留する」で進捗・素材・支払い・負債・不具合を残して別の作品へ移れます。自由企画の一覧から「再開する」で続きを作れます。制作中と保留中は合計24企画までです。「機能・内容を追加」では、完了した仕事を残して機能・数量・対応環境などを増やせます。ひとり用から協力プレイ、無料から買い切りなどの追加も、既に積んだ実装や費用を残す構成なら選べます。既存機能の取消、ジャンル・基本表現・主操作・エンジンの差し替えはできません。コードが増えるだけで品質や売上が上がるわけではありません。

自作エンジンで完成・検証した基盤は、同じ人生の次作へ流用できます。基盤の一部の制作作業を省けますが、接続の検証と未整理部分は引き継ぎます。制作記録の配信・体験版・展示会・試遊募集を追加し、知ってもらう準備にも作業と費用をかけられます。公開した企画では、組み合わせについて確かめた知見を得られます。まだ作っていない組み合わせの結果は、選択画面では分かりません。

「案を出してもらう」は現在の知識・資金・制作経験に合う下書きを選びます。「自動企画」をONにすると、企画選び、必要な学習先、素材とコードの作業先、修正、支払い、公開までを自動で切り替えます。作業を進める入力や設備は必要です。設備を持たない序盤なら、表示された作業をクリックやタイピングで進めます。設備の購入と再出発は自分で行います。

DLCを選ぶ場合は本編となる自作の有料作品を指定します。本編がなくても案を作って制作できますが、DLCの公開には、同じ人生で先に本編を発売する必要があります。

## 入力と学習

| 操作 | 内容 |
| --- | --- |
| クリック | 選んだ作業を1入力分進める |
| コードタイピング | 出題コードを正確に入力。事務では原票をCSV化し、完入力で追加報酬 |
| 作業タブ | 日銭／写経・学習／ゲーム開発の切替 |
| 学習分野 | 文法・設計・描画・基盤。必要な分野の無料教材を開くか教本を購入 |
| レビュー・整理 | 必要理解度を満たして、不具合を修正し、余った工数で構造を整理 |
| 途中ビルド・テスト | 小さな変更ごとに自動検証。手動で最新版を確認することも可能 |
| 自由企画 | 遊び・機能・規模・作り方・販売方法を選び、制作・拡張・保留・再開を行う |
| ロードマップ | 固定企画の規模・必要条件を確認し、企画選択や再出発を行う |
| 設定 | 打鍵音、演出削減、コメントの言語、一時停止、セーブの書き出し・読み込み |

コード表示をクリックすると、次の文字の位置で直接タイプできます。正解はすぐ確定し、誤入力だけが赤字で残ります。Backspaceや選択編集で直せます。確定済みの文字は消して再入力できず、重複報酬も発生しません。数字キーで作業タブは切り替わりません。

改行はEnter、字下げはTab。Tabは正解に合わせてタブ文字または最大4空白を入力し、報酬は1打鍵分です。Shift+TabかEscでコードからフォーカスを外せます。モバイルでは入力位置をタップして画面キーボードを開きます。半角で入力し、貼り付け・ドロップ・キー長押しは数えません。全角補正や専用のIME変換処理はありません。講座の原典に含まれるUnicode文字はそのまま残しています。

正解文字で基礎入力の12倍、正確な完入力なら追加分を含め16倍の作業量になります。設備なしでは300打鍵/分の正確なタイピングが8クリック/秒の10倍に相当します。学習・開発・修正も同じ基準です。所有設備が増えると正確な入力を反映できる範囲も広がり、稼働スイッチのON/OFFでこの能力は変わりません。誤入力は訂正でき、完入力ボーナスが減ります。

学習は次の3つから選べます。無料教材と有料教本で利用できる内容は共通です。

- **コード演習**：C++ / C# / Rust / Go / Python / Java / SQL / Luaの8言語、4分野、512本。入力データを変えた8,192問です。言語固有のコンテナ・所有権・コールバックなども扱います。
- **言語別の講座**：ExercismのMIT教材1,062演習を3,562入力区間へ整理しています。名前空間・クラス・クロージャの文脈を保ち、変更のない支給部分は参照欄へ分けています。入力前に日本語の目的・変数の用途を確認し、課題原文・周辺ファイル・作者・出典も参照できます。
- **参考コードを読む**：コードの結果を4択で答えます。初回正解で学習量を獲得し、回答後に計算過程を確認できます。同じ題材の再回答には報酬がありません。回答記録は再出発後も残ります。

英語コメントを1つ入力し終えると、コード内のその箇所が日本語に置き換わります。設定で英語表示に戻せます。元の英語で正誤と保存位置を判定し、次の問題に古いコメントは残しません。Pythonのdocstringにも対訳を同梱しています。

コード演習は開発用環境で実行結果を照合し、完入力後に戻り値や問い合わせ結果を表示します。Exercism講座の参考実装には同じ実行検証をしていないため、実行成功とは表示しません。ブラウザで任意のコードをコンパイルする機能はありません。教材の完了数と、現実の言語習得は別です。

## 制作と公開

現在企画の必要文字数・必要理解度・不足分野を確認し、目標ボタンから学習・開発へ進めます。理解度が必要量の半分以下なら制作は進まず、半分を超えると試作、必要量を満たすと通常の制作ができます。表示と判定には確認済みの理解度を使います。

開発中は小さな変更ごとにビルド・テストを繰り返します。深刻な失敗は学習・修正して復旧します。技術的負債は、今は動くコードに残る将来の変更しづらさです。仮実装や継ぎ足し、経験の浅さから生まれ、追加時の効率と不具合に影響します。負債が残っているだけで公開を止めることはありません。

「開発方針を選ぶ」で速さと後の整理量を選べます。「コードの状態と検証履歴」を開くと、負債の内訳と検証結果を確認できます。「レビュー・整理」はまず不具合を修正し、余った工数で負債を減らします。自作ライブラリを使うと、前作の未整理部分の25%も流用します。初購入時には引継ぎ量を購入前に表示します。

制作100%・正常なビルド・公開基準以下の不具合で「作品を公開」が押せます。末尾の未検証分も公開前に確認します。ロードマップで新作へ進むと自動開発は停止するので、次の必要条件を見て再開してください。自由企画の自動制作は「自動企画」で制御します。ロードマップのAAAは6.2億文字相当で、制作途中から検証を繰り返します。

## 資金と販売

日銭ワークは原票画像のデータ化です。伝票番号・日付・品名・数量・単価をCSVへ整えます。未入力の正解は表示しません。原票と入力位置を同時に見ながら作業でき、詳しい整形規則は開閉式です。プログラミングの理解度は増えません。

各人生で受託するのは50件、合計5,000作業量の短期契約です。手動とOCRで同じ受託分を使い、納品後に補充されません。新規案件は100作業量ごとに¥100で精算し、途中の進捗は保存します。¥500のOCRは買い切り1台で、受託分を自動処理します。10件に1件の誤納品は報酷取消と依頼元への再提出手数料20%が発生します。「OCR再納品」で誤った項目を訂正すると報酬は回収できますが、手数料は戻りません。訂正は新しい受託枠を消費しません。

ロードマップの最初の2本は無料です。小規模ローグライト以降は、必要理解度を満たし品質60以上なら販売できます。自由企画では無料・買い切り・DLC・期間契約・基本無料＋外見商品・広告・任意支援から選べます。発売前に価格と販売見込を確認し、発売時の販売分と、その後に徐々に売れる分を受け取ります。需要には限りがあり、毎秒の売上は減っていきます。完成だけで決まった額を支給する報酬はありません。同規模の新作も制作でき、旧作品を停止・再開しても販売需要は補充されません。

| 支払い | 支払先・条件 |
| --- | --- |
| 販売・決済手数料 | ロードマップではストアへ売上の25%。自由企画では選んだ配信先の条件を使い、入金時に一度だけ控除 |
| 素材の購入・制作委託 | 小商業は素材ストア・制作者のライセンス、3D以降はアーティスト・音響制作者へ。作品ごとに任意発注 |
| 公開中のサービス利用料 | ホスティング会社、P2P接続仲介、請求・感覚I/O基盤など、選んだ機能の提供元へ公開中の時間分。日次精算 |

未公開作品に公開中のサービス利用料はかかりません。オフラインでも販売契約や感覚I/Oなどの有料サービスを選べば、その用途の費用が発生します。教本・道具・設備は買い切りです。ロードマップの素材購入・外注は品質を高めます。自由企画の素材調達は自作作業を支払いへ置き換える選択で、品質を自動加点しません。用途・支払先・金額は支払い前に確認できます。

公開中のサービス利用料は公開前にも表示します。公開作品の一覧で「公開停止」を選ぶと、以後の売上と稼働料が止まります。停止前の利用分は精算し、再開すると残っていた販売分と稼働料が再開します。売上が減っても稼働料は続くため、作品ごとの収支を確認してください。「サーバー運用の最適化」は稼働料を25%削減します。事務所の自動契約はありません。

## セーブと更新

- 5秒ごと、タブを隠したとき、ページを離れたときにブラウザへ保存します。容量に余裕があれば直前の保存もバックアップし、破損時は復旧を試みます。
- 設定からJSONで書き出し・読み込みができます。読み込みは現在の進行を置き換えます。
- 離席中は最大8時間分の自動作業・有限売上・サーバー代を計算します。計算した時間分だけ販売需要を消費します。通常は購入・公開・再出発を自動では行いません。「自動企画」がONなら自由企画の制作と公開も進みますが、設備購入と再出発は行いません。
- Web Locks対応ブラウザでは、別タブからの上書きを防ぎます。ブラウザデータを削除する前にセーブを書き出してください。

保存キーは `code-typer-idle:save:v1`。データをサーバーへ送信しません。

旧セーブの現金・理解度・設備・作品・資産と制作進行を維持します。旧版で到達した規模は、その人生の間は引き続き制作可能です。旧作品の完成経験を引継ぎ候補に加え、次の再出発から新しい経験条件を使います。既公開作品の過去の入金は再計算せず、今後の定額売上を有限の販売残高へ移します。受注済みの旧案件は単価・原票・進捗を保ちます。

配信ファイルには内容のハッシュを付け、異なる版の混在を防ぎます。起動時・タブへ戻ったとき・60秒ごとに更新を確認し、更新があれば「保存して更新」を表示します。保存成功後に再読み込みします。通信できない間はプレイを継続します。更新のためにブラウザデータを消す必要はありません。

指紋付き配信より前のHTMLが強くキャッシュされている場合は、[更新用URL](https://velgail.github.io/code-typer-idle/?v=2.1.0)を一度開いてください。

Node.js 22以降でルールを検証できます。ビルドとルールテストには外部パッケージは不要です。

```sh
npm run build
npm test
```

ソース変更後はビルドし、`docs/` の生成物もコミットしてください。CIは再ビルドとの差分を検査します。進行の計測は `npm run balance -- --write`。固定した購入・再出発方針による比較であり、実プレイの所要時間を保証するものではありません。

自由企画で使うジャンル・機能・テーマ・制作基盤・通信・販売などの定義と、制作・公開・追加仕様の計算は[PLANNING.md](PLANNING.md)にまとめています。`npm run planning` で登録構成ごとのコード・素材作業・必要技術・費用を比較し、`--plan` で任意の企画JSONを検証できます。

ブラウザテストにはPlaywrightが必要です。

```sh
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
```

既存サーバーを使う場合は `CTI_TEST_URL`、Chromiumの実行パスを指定する場合は `CHROMIUM_PATH` を設定できます。スクリーンショットはGit管理外の `work/` に出力します。

ルール検証では自由企画の依存・互換制約・数量・拡張・素材・保留・保存・有限販売・自動企画に加え、受託上限・経験・再出発・保存互換を扱い、ブラウザ検証では実入力、誤入力編集、教材の切替、公開、作品選択、表示・フォーカス、キャッシュ更新を扱います。初周AAA3〜7日という旧版の到達条件は廃止しています。
